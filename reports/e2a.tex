\section{E2A: Comparison of Representation Pipelines}
\label{sec:e2a}

E2A compares four representation pipelines under the same CUB-200-2011
class-disjoint protocol. M1 and M2 are fixed representations; M3 and M4 may
use learned aggregation. The winner is selected by integer test-selection
Hits@1, then Hits@2/4/8, total optimized parameter count, and fixed M1--M4
order. Validation still selects learned checkpoints. Classes 100--199 then
select among M1--M4, so they are not an untouched final test.

\subsection{M1: Final-layer CLS token}

M1 uses the frozen 768-dimensional final-layer DINOv3 CLS token, L2
normalization, cosine similarity, and image-ID self-match exclusion. It has no
trainable parameters, so training-seed variance does not apply. Table entries
remain pending until the validation run is executed. Rankings retain the
ordered Top-100 candidate IDs and cosine scores for later E2B construction,
reranking, and failure analysis.
